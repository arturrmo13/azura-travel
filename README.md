# AZURA Travel — лендинг туроператора

Статический лендинг туроператора: конструктор тура с барабаном скидки, горящие путёвки, отзывы, бот техподдержки, заявки с переходом в Telegram. Люкс-оформление (нуар + золото), светлая и тёмная темы, мобильная версия.

## Структура

```
azura-travel/
├─ index.html   — разметка страницы
├─ styles.css   — все стили (токены тем, компоненты, адаптив)
├─ app.js       — вся логика (конструктор, календарь, барабан, фильтры, бот, модалки)
└─ README.md
```

Внешние зависимости (грузятся с CDN, нужен интернет):
- **Google Fonts** — Fraunces + Inter.
- **images.unsplash.com** — фото направлений/отелей (демо, заменить на свои/лицензионные).
- **randomuser.me** — аватарки в отзывах и карточке «кто-то забронировал» (демо).

Если какое-то фото не загрузилось — автоматически подставляется градиентная обложка (битых картинок не будет).

## Запуск локально

Открыть `index.html` в браузере. Или поднять локальный сервер (чтобы проверить с телефона в той же Wi-Fi сети):

```powershell
cd azura-travel
python -m http.server 8080 --bind 0.0.0.0
# ПК:    http://localhost:8080/
# Телефон: http://<IP-вашего-ПК>:8080/
```

## Что заменить перед запуском (плейсхолдеры)

| Где | Что |
|---|---|
| `app.js`, вверху | `TG_MANAGER`, `TG_SUPPORT` — юзернеймы ваших Telegram-ботов (сейчас `azura_travel_bot` / `azura_support_bot`) |
| `index.html` | Название бренда **AZURA**, логотип (SVG в шапке и футере) |
| `index.html`, футер | Реестровый номер туроператора (РТО), реквизиты |
| `app.js`, `DEST` / `HOTELS` | Направления, отели, цены, фото — демо-данные |
| `app.js`, `REVIEWS` | Отзывы — демо (40 шт.) |
| фото | Unsplash-ссылки → свои фото отелей/направлений |

## Деплой (хостинг)

Это статический сайт — подходит любой статический хостинг.

**GitHub Pages** (бесплатно): запушить репозиторий → Settings → Pages → Branch `main`, папка `/root` → сайт на `https://<user>.github.io/azura-travel/`.

**Netlify / Vercel**: подключить репозиторий, build-команда не нужна, publish directory — корень.

**Свой VPS (nginx)**: положить файлы в корень сайта, отдавать `index.html`.

## Дальше: бэкенд (не реализовано)

Переход в Telegram работает без сервера (ссылки `t.me/...`). Но **интеграция с CRM по API-ключу требует бэкенда**: ключ нельзя держать в коде страницы. Схема: форма заявки → POST на серверную функцию (Vercel/Netlify Functions или Node на VPS) → функция с секретным ключом пишет лид в CRM и уведомляет Telegram-бота. Это следующий этап.

## Защита кода

Полностью «скрыть» фронтенд нельзя (браузер всегда скачивает исходник). Для прода: минификация + обфускация `app.js`, вынос ценной логики (цены, ключи) на бэкенд. Это тоже следующий этап.
